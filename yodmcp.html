YodMCP is a production-oriented Agent OS kernel: multi-graph memory, tasks, skills, agent-to-agent messaging, attestation, telemetry, and plan-based billing — served over MCP from a single Python package.

System

What ships in the kernel

Eight subsystems, one server process.

[mem]

Multi-graph memory

Structured recall across multiple knowledge graphs, not one flat store.

[task]

Tasks

Create, track, and resume long-running work as first-class tasks.

[skill]

Skills

Reusable agent instructions served as skills:// resources with SKILL.md files.

[a2a]

A2A

Serve an Agent Card and exchange messages and tasks with other agents.

[tee]

TEE attestation

Attestation baked in — simulated on Pro, Nitro/SGX hooks on Enterprise.

[otel]

OpenTelemetry

Traces and metrics wired through the kernel, ready for your collector.

[cache]

Caching

Response caching to keep repeated calls fast and cheap.

[bill]

Billing

Plan catalog with soft quotas enforced right at the tool gate.

Quick start

Boot it yourself

Four commands from clone to a running kernel, API, and A2A endpoint.

bash
$ pip install -e ".[dev]"
$ yodmcp
$ yodmcp-api --port 8080
$ yodmcp-a2a --port 9000
