# WebMCP — YodMCP

Page: `web/dashboard.html`, mounted by `yodmcp-api` at `/web` and `/dashboard`.

Public tools: `health`, `ready`, `discovery`.
Authenticated tools (optional API key field on the page): `list_skills`, `audit_recent`.
HITL decide and billing checkout are not WebMCP tools.
MCP / `/mcp` remains the system of record.
